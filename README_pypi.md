# VCF Generator Lite with Tkinter

VCF Generator Lite is a simple and efficient tool that converts contact lists into a single vCard (`.vcf`) file.

For more information, please visit the [Gitee repository](https://gitee.com/hellotool/VCFGeneratorLiteWithTkinter/).
