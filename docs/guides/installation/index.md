# 安装与启动

根据您的软件包类型，选择对应的安装指南。

> [!TIP]
>
> 安装前请查阅 [兼容性](../../reference/compatibility.md) 确认系统要求。

| 平台    | 软件包类型       | 需要安装 | 指南                                       |
| ------- | ---------------- | -------- | ------------------------------------------ |
| Windows | 安装程序（推荐） | 是       | [Windows 安装程序](./windows-installer.md) |
| Windows | 便携包           | 否       | [Windows 便携包](./windows-portable.md)    |
| 跨平台  | Python Wheel     | 可选     | [Python Wheel](./wheel.md)                 |
| 跨平台  | Python ZIP 应用  | 否       | [Python ZIP 应用](./zipapp.md)             |
