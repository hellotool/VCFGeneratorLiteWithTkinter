# Windows 便携包

无需安装，适合放在 U 盘中随身携带使用。

**文件**：`VCFGeneratorLite-v<应用版本>-win-amd64-portable.zip`

您可以从 [Gitee 发行版][release-gitee] 或 [GitHub Releases][release-github] 下载。

## 使用步骤

1. 将 `.zip` 文件解压到目标位置（如 `D:\Portable\VCFGeneratorLite`）。
2. 双击 `vcf_generator_lite.exe` 启动应用。

> [!IMPORTANT]
>
> 请勿删除解压目录中的其他文件，它们是应用运行所必需的。

## 卸载

直接删除整个解压目录即可。
