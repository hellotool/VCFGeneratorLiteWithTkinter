# 快捷键速查

VCF 生成器 Lite 支持以下快捷键：

## 主窗口

| 功能     | Windows                      | Linux                                         | macOS                                  |
| -------- | ---------------------------- | --------------------------------------------- | -------------------------------------- |
| 开始生成 | <kbd>Ctrl</kbd>+<kbd>G</kbd> | <kbd>Ctrl</kbd>+<kbd>G</kbd>                  | <kbd>⌃</kbd> <kbd>G</kbd>              |
| 撤销     | <kbd>Ctrl</kbd>+<kbd>Z</kbd> | <kbd>Ctrl</kbd>+<kbd>Z</kbd>                  | <kbd>⌘</kbd> <kbd>Z</kbd>              |
| 重做     | <kbd>Ctrl</kbd>+<kbd>Y</kbd> | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>Z</kbd> |
| 剪切     | <kbd>Ctrl</kbd>+<kbd>X</kbd> | <kbd>Ctrl</kbd>+<kbd>X</kbd>                  | <kbd>⌘</kbd> <kbd>X</kbd>              |
| 复制     | <kbd>Ctrl</kbd>+<kbd>C</kbd> | <kbd>Ctrl</kbd>+<kbd>C</kbd>                  | <kbd>⌘</kbd> <kbd>C</kbd>              |
| 粘贴     | <kbd>Ctrl</kbd>+<kbd>V</kbd> | <kbd>Ctrl</kbd>+<kbd>V</kbd>                  | <kbd>⌘</kbd> <kbd>V</kbd>              |
| 全选     | <kbd>Ctrl</kbd>+<kbd>A</kbd> | <kbd>Ctrl</kbd>+<kbd>/</kbd>                  | <kbd>⌘</kbd> <kbd>A</kbd>              |
