# 输入格式

本文详细说明 VCF 生成器 Lite 的联系人输入格式。

## 基本格式

每行一个联系人，字段之间使用空格或制表符（Tab）分隔：

```text
姓名 电话 备注
```

应用会自动识别行中的电话号码（基于您选择的号码格式）。识别逻辑如下：

- 找到电话号码后，电话号码左侧的全部内容作为姓名。
- 电话号码右侧的全部内容作为备注。

### 字段说明

| 字段 | 是否必填 | 说明                               |
| ---- | -------- | ---------------------------------- |
| 姓名 | 否       | 联系人姓名，支持中英文及多字节字符 |
| 电话 | 是       | 电话号码，必须匹配已启用的号码格式 |
| 备注 | 否       | 附加信息，如公司、职位、关系等     |

## 格式规则

### 分隔符

- 支持空格和制表符（Tab）作为分隔符。
- 多个连续空格或制表符会被自动合并为一个。
- 混合使用空格和制表符时，同样会被合并。

### 特殊字符

- 字段内可以包含空格（如复姓、多字名）。
- 备注字段可以包含任意字符，包括空格和标点。

## 输入示例

### 标准格式

```text
张三	13800138000	公司同事
李四	13900139000
王五	13700137000	大学同学
```

解析结果为：

| 姓名 | 电话        | 备注     |
| ---- | ----------- | -------- |
| 张三 | 13800138000 | 公司同事 |
| 李四 | 13900139000 |          |
| 王五 | 13700137000 |          |

### 混用空格和制表符

```text
张三   13800138000   公司同事
李四	13900139000
王五   	13700137000	大学同学
```

解析结果为：

| 姓名 | 电话        | 备注     |
| ---- | ----------- | -------- |
| 张三 | 13800138000 | 公司同事 |
| 李四 | 13900139000 |          |
| 王五 | 13700137000 |          |

### 姓名与备注包含空格

```text
张伟 项目经理	13800138000	部门：技术部 工号：023
```

解析结果为：

| 姓名          | 电话        | 备注                   |
| ------------- | ----------- | ---------------------- |
| 张伟 项目经理 | 13800138000 | 部门：技术部 工号：023 |

## 无效条目

以下情况为无效条目：

1. 行内所有字段均不匹配任何已启用的号码格式。
2. 行内无法解析出有效的姓名和电话组合。

生成结束后，应用会弹出无效条目窗口，列出所有无法识别的行。您可以双击任意条目在主窗口中定位并修正。
