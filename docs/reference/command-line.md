# 命令行参数

通过命令行启动 VCF 生成器 Lite 时，可附加以下选项：

## 参数说明

| 参数 | 长参数      | 说明                                                    |
| ---- | ----------- | ------------------------------------------------------- |
| `-v` | `--verbose` | 增加输出级别。可重复使用：`-v` 为信息级，`-vv` 为调试级 |
| `-q` | `--quiet`   | 减少输出级别。可重复使用：`-qq` 仅显示错误              |
| `-V` | `--version` | 显示版本号并退出                                        |
| `-h` | `--help`    | 显示帮助信息并退出                                      |

## 使用示例

### 显示详细信息

```bash
vcf-generator-lite -v
```

输出信息级别的日志，包括任务开始与结束、处理统计、无效行提示等。

### 显示调试信息

```bash
vcf-generator-lite -vv
```

输出调试级别的日志，包括号码检测器加载、进度通知等详细信息。

### 静默模式

```bash
vcf-generator-lite -qq
```

仅输出错误信息，适合脚本调用或自动化场景。

### 查看版本

```bash
vcf-generator-lite -V
```

输出当前版本号，例如：`VCF 生成器 Lite 5.0.4`。

### 查看帮助

```bash
vcf-generator-lite -h
```

显示完整的命令行帮助信息。
