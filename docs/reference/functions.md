# 应用功能

本文介绍 VCF 生成器 Lite 的各项功能，帮助您更高效地处理联系人数据。

## 清除引号

从电子表格（如 Excel）粘贴数据时，可能会带入多余的引号。选择 **编辑 > 清除引号** 可快速移除文本中所有成对的引号。

### 使用场景

粘贴前：

```text
"张三"	"13800138000"	"公司同事"
```

粘贴后使用 **清除引号**：

```text
张三	13800138000	公司同事
```

## 号码格式

应用支持多种电话号码格式识别。启动时会根据系统语言自动选中匹配的格式。

### 查看与修改号码格式

通过 **选项 > 号码格式** 查看当前选中的格式，或选择/取消选择特定的号码格式。

### 全选与取消全选

通过 **选项 > 号码格式 > 全选** 可快速选中或取消全部格式。当您需要识别非常规号码格式时，可尝试全选所有格式。

## 无效条目定位

生成结束后，若存在无法解析的联系人，会弹出无效条目窗口。

### 快速定位

双击无效条目列表中的任意条目，主窗口会自动滚动到对应行并高亮显示，便于快速修正。

### 批量修正

您可以在无效条目窗口中查看所有问题行，然后在主窗口中统一修正后重新生成。
