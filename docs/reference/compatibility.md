# 兼容性

本文介绍应用的系统要求、vCard 兼容性以及其他已知问题与规避方法。

## 系统要求

| 软件包类型               | 系统环境                        |
| ------------------------ | ------------------------------- |
| Windows 安装程序、便携包 | Windows 8.1 或更高版本          |
| Python ZIP 应用          | Python 3.12 或更高版本、Tkinter |

> [!TIP]
> 如果您需要在 Windows 8 或更低版本中使用本应用，请参阅 [在旧版 Windows 中运行](../troubleshooting/runs-on-older-windows.md)。该通过这些方式运行应用**可能存在安全和稳定性风险**，请谨慎使用。

## vCard 文件兼容性

本应用生成的 vCard 文件遵循以下规范：

- **vCard 版本**：2.1
- **支持字段**：姓名（`FN`）、电话号码（`TEL`）、备注（`NOTE`）
- **编码**：UTF-8（通过 Quoted-Printable 编码）

vCard 2.1 是兼容性最广泛的版本，几乎所有通讯录应用（包括功能手机）均支持。本应用选择 2.1 以保证最大兼容性。

一些应用可能不支持 UTF-8 编码，导致非英文字符显示为乱码：

- Windows 联系人
  - **规避方法**：勾选 **使用 Unicode UTF-8 提供全球语言支持**，详见 [常见问题](../troubleshooting/faq.md)。
